# Panosphere landing page

A responsive, accessible one-page website for Panosphere—a calm, journal-inspired organization workspace for college students.

## Run locally

No build step or dependencies are required. Open `index.html` directly, or serve the folder with:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included interactions

- Responsive mobile navigation
- Keyboard-accessible FAQ accordion
- Accessible “Add a new entry” dialog
- Manual demo entries saved to browser local storage
- Drag-and-drop or file-picker image preview
- Reduced-motion support and visible focus states

## Before publishing

Replace `[ADD CONTACT EMAIL]` in `index.html` with the business contact address. Gmail, Canvas, OCR, and calendar integrations are presented as planned product functionality and are not simulated by this static website.
